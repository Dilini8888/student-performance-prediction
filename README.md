# Student Performance Prediction

A beginner-friendly machine learning project that predicts students' final scores using academic and lifestyle-related features.

## Project Overview

This project explores student performance data and develops machine learning regression models to predict final scores.

## Dataset

The dataset contains 500 student records with the following features:

- Age
- Study Hours
- Attendance
- Previous Score
- Assignment Score
- Sleep Hours
- Internet Hours
- Final Score

## Exploratory Data Analysis

The project includes:

- Dataset inspection
- Missing value checking
- Duplicate checking
- Descriptive statistics
- Scatter plots
- Correlation analysis

## Machine Learning Models

Two regression models were implemented:

1. Linear Regression
2. Random Forest Regression

## Model Evaluation

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Additional Analysis

The project also includes:

- Linear Regression coefficient analysis
- Random Forest feature importance
- Actual vs Predicted visualizations
- New student score prediction

## Example Prediction

For a sample student's academic and lifestyle information, the Random Forest model predicted a final score of approximately **75.12**.

This project uses a synthetic dataset and is intended for learning and portfolio practice. The model results should not be interpreted as real-world student performance predictions.
